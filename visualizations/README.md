## Description

Catch-all folder for spray charts, plots, and other graphics used in the Final Report and Executive Summary.

## Note

I made the decision to forgo a more orderly format, with sub-folders and such, because I was constantly making changes to graphics/where they were used in the report. I tested versions of the `visualizations` folder with different sub-folders dedicated to sections, spray charts, etc. It was impractical to continue changing my filing system as the report came together, so I opted for a grab bag.
